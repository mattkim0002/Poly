=== CURRENT STRATEGY ===

The bot runs TWO strategies every 15 seconds:

STRATEGY 1: ARBITRAGE (Zero Risk)
- Scans all crypto 5-min up/down markets
- Checks real orderbook prices for Yes and No sides
- If Yes_ask + No_ask < $0.98 → buys BOTH sides
- Market resolves → guaranteed $1.00 payout regardless of outcome
- Profit = $1.00 - total_cost - 2% fee
- Inspired by @0x8dxd who made $2.38M with this approach
- If one side fails to fill, cancels the other (no naked exposure)

STRATEGY 2: MOMENTUM + CLAUDE GATE (Directional)
- Detects real-time Binance price movements (0.04%+ in 60 seconds)
- Requires 2+ confirming signals (volume spike, acceleration, orderbook, whales)
- TradingView analysis as optional confirmation
- Claude AI (Sonnet) reviews ALL raw data and APPROVES or REJECTS every trade
- If Claude says no → trade is blocked
- If Claude is unavailable → trade is blocked (safety first)
- Only executes when multiple independent signals agree


=== BANKROLL MATH ($35 account) ===

Position Sizing:
- Polymarket minimum order: $5 (14.3% of $35 bankroll)
- Kelly optimal for 55/45 edge at even odds: 10% ($3.50)
- Since minimum is $5, every trade is slightly above Kelly optimal
- This means we MUST be very selective → Claude gate is essential

Risk Limits:
- Max 3 positions at once = $15 at risk (43% of bankroll)
- Daily loss cap: $7 (20% of bankroll) → bot stops for the day
- Drawdown halt: 35% ($12 loss) → bot stops entirely
- Drawdown half: 20% ($7 loss) → position sizes halved

Stop Loss / Take Profit:
- Stop loss: 40% (5-min markets resolve to $0 or $1 naturally)
- A 6.15% stop was getting triggered by normal noise → killing winners
- Take profit crypto: 20% (lock gains if price jumps before resolution)
- Take profit other: 30%

--- Phase 5: Risk & Learning ---

16. Adaptive learning system:
    - Classifies markets: crypto, politics, geopolitical, climate, finance, other
    - Tracks win rate and P&L by category
    - Winning categories: +edge boost, 1.25x position size
    - Losing categories: -edge penalty, 0.5x position size
    - 0% win rate over 3+ trades → skip category entirely
    - Crypto is NEVER skipped (just reduced size)

17. Loss pattern learning (Perplexity addition):
    - Records every stop-loss exit by category + price range
    - If same pattern triggers 3+ stop-outs → auto-avoids

--- Phase 6: Critical Bug Fixes ---

18. DD=0.0 BUG FIX (was blocking ALL trades for 40+ cycles):
    - Bug: position_sizing used cash-only ($2.68) vs peak ($76.82)
    - This calculated 96.5% "drawdown" → DD=0.0 → $0 position size
    - Fix: now uses total equity (cash + positions) for drawdown calc
    - Fix: reset peak equity on every startup

19. Stale peak equity fix:
    - reset_peak_equity() now caps ALL historical peaks
    - Prevents old peaks from permanently blocking trades

20. Dead token fix:
    - Tracks tokens with no orderbook in memory
    - Stops retrying them every 10 seconds (was spamming 404 errors)

21. Unfilled order fix:
    - Only sells positions that actually filled on Polymarket
    - Unfilled orders marked as "cancelled" in DB
    - Cancel all orders before selling (frees locked balance)

22. Position sync on startup:
    - Fetches real Polymarket positions via data API
    - Imports into local DB so bot knows what it owns
    - Uses live position values (not stale DB cost basis)

23. Unfilled order fix (latest):
    - Orders sitting at 0/8 filled because price was at midpoint
    - Increased price improvement to 3 cents (crosses the spread)
    - Cancel all stale orders on startup to free locked capital

24. ARBITRAGE SCANNER (new):
